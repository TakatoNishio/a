一次元拡散方程式シミュレータ

Gaussian分布が拡散によって広がる時間発展を計算します。

計算条件
方程式：∂u/∂t = D ∂²u/∂x²
初期条件：u(x,0)=exp[−(x−x₀)²/(2σ₀²)]
初期値パラメータ：x₀ = 5、σ₀ = 1、初期ピーク高さ u(x₀,0)=1
計算領域：0 ≤ x ≤ 10　／　格子点数 N = 181　／　Δx = 10/(N−1) ≈ 0.05556
時間積分：陽的Euler法　／　空間差分：2次中心差分
内部時間刻み：Δt ≤ 0.45 Δx²/(2D)（拡散数 DΔt/Δx² ≤ 0.225）
表示する最大時間：10 s
境界：各時刻のGaussian解析解の値を左右端に与える時間依存Dirichlet境界
初期条件：Gaussian ピーク高さ = 1.0000000000 t = 0.000
解析解との誤差 —
Gaussian解析解を破線で重ねています。境界は解析解の値を与えるため、有限計算領域でも比較できます。
拡散係数を設定して「計算」を押してください。

解析解との比較
相対L1：誤差の絶対値の総和を解析解の絶対値の総和で割った値。全体的なずれを表します。
相対L2：誤差の二乗和平方根を解析解の二乗和平方根で割った値。大きなずれをL1より強く反映します。
相対L∞：最大誤差を解析解の最大絶対値で割った値。局所的に最も悪いずれを表します。
いずれも0に近いほど良く、0.01はおおよそ1%の相対誤差です。解析解のノルムがほぼ0になる場合のみ、その指標は絶対誤差へ自動的に切り替えます。
収束性チェック
同じ物理条件を3段階の格子で計算し、粗格子↔中格子・中格子↔細格子の差から自己収束次数を評価します。 解析解がない場合にも「格子を細かくすると同じ解へ近づくか」を検証できます。 安定条件に応じて内部時間刻みも格子とともに細かくなるため、ここで得る p は空間離散だけではなく時間離散も含む「実測の総合収束次数」です。
周期境界では N, 2N, 4N、非周期境界では端点が一致するよう N, 2(N−1)+1, 4(N−1)+1 を使います。2Dは計算量が急増するため上限を小さくしてください。

方程式比較モード
選択した複数の方程式・条件を比較します。通常比較では初期条件・領域などを共通にし、境界条件は比較しやすいよう周期境界に統一します。詳細設定では、各ケースに保存した設定一式（方程式固有設定・境界条件・速度場・地形など）を使用します。「比較開始」を押すと選択した数だけ比較計算を実行し、同じ時刻の結果を並べて表示します。通常の再生ボタンを押す必要はありません。
注意：異なる方程式の色や数値は物理量・単位・規格化が異なる場合があるため、絶対値を直接比較するのではなく、主に形状・伝播・拡散・パターン形成などの時間発展を比較してください。同じ方程式の条件比較では絶対値比較も意味を持ちます。
